# Аддоны: работа и выкладка

Исходники — `agent/addons/<Папка>/`. Karasuoshi Rested Buff опубликован на сайте гильдии. Karasuoshi Legacy — личный план, на сайте его нет; выкладывать только по просьбе.

## Правка
1. Ошибку попроси целиком (текст Lua error, строка, BugSack, если есть). Найди причину, правь минимально.
2. Только разрешённый API Blizzard: никакой автоматизации действий в бою и игрового процесса. Нужное действие без защищённой кнопки невозможно — скажи.
3. Клиент на старте может отличаться от беты: Interface в `.toc` (сейчас 16001, 11508, 11507), имена API, id квестов. Сверяй по `/dump select(4, GetBuildInfo())` и ошибке.
4. Русский и английский клиент: названия бери через API, а не строкой, где можно. `string.lower` кириллицу не меняет.
5. Проверь синтаксис: `luac -p` (нет `luac` — поставь или проверь `luaparser`). Логику в игре проверяет Артём: «проверено» говори только после его ответа.
6. Подними `## Version` в `.toc`.

## Выпуск для себя
`python3 agent/tools/vypusk.py addon <Папка> /mnt/user-data/outputs/forever`, затем SendUserFile. Шаги Артёму: закрыть игру или выйти на экран персонажей; распаковать zip в `<папка игры>\Interface\AddOns\` с заменой; войти или `/reload`. Папку игры спроси один раз и запиши в `Персонажи.md`.

## Выкладка на сайт (Rested Buff, после «да»)
1. В `agent/site/addons/addons.json`: `version`, `released`, `updated`, запись первой в `changelog` простым языком. `game` — актуальная версия клиента.
2. Та же команда `vypusk.py` соберёт второй архив `site_<Папка>-<версия>.zip` и остановится, если версии расходятся.
3. Коммит, архив на D через device_commit_files в `D:\Hive\Forever\Выкладка\`.
4. Загрузка на Beget — по `reference/site.md`. `download.php` при выпуске не меняется: архив для игроков сайт собирает сам.
5. Проверка: открыть `addons.html`, версия и список изменений новые; скачать zip по кнопке, внутри папка с файлами. «На сайте» — только после проверки.
