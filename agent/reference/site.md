# Сайт гильдии Reported: работа и выкладка

Сайт на Beget, PHP без базы, адрес в `index.html` корня репозитория. Страница на GitHub Pages только переводит на него и не меняется без просьбы.

- `index.php` камень возвращения; `roster.html`, `roster.css`, `guild.js` ростер; `admin.html`, `api.php` админка и приём записей; `addons.html`, `addons/` аддоны; `img/` картинки.
- Исходники `agent/site/` собраны 04.11 из архивов на D по порядку выпуска. **Живой сайт мог отличаться:** перед первой правкой файла сверь его с живой версией, а если её не прочитать, попроси Артёма скачать этот файл из файлового менеджера.

## Никогда
- Не трогать и не класть в пакет `config.php` и `data/` на сервере: там пароль админки и записи гильдии. Записей нет в репозитории и быть не должно.
- Не писать пароль админки в чат, git и файлы. В админку заходит Артём.
- Репозиторий публичный: личных данных игроков сюда не класть.

## Правка
1. Правь в `agent/site/`, по возможности проверь страницу локально (PHP или браузер) и глазами на телефонной ширине.
2. Покажи, что поменяется; публикация только после «да».

## Выкладка
1. `python3 agent/tools/vypusk.py site /mnt/user-data/outputs/forever <файлы>` собирает `site_update.zip`: только изменённые файлы, пути как на сервере.
2. Коммит, архив на D через device_commit_files в `D:\Hive\Forever\Выкладка\`.
3. Ручной шаг: открыть [панель Beget](https://cp.beget.com) → «Файловый менеджер» → папка сайта → `public_html`; загрузить архив; правой кнопкой → «Распаковать» в эту же папку с заменой; архив удалить.
4. Проверка: открыть страницу, обновить без кеша, камень и ростер работают. Если открыть не вышло, скажи об этом и попроси Артёма проверить. «На сайте» — только после проверки.
5. Сломалось — вернуть прошлую версию файлов из git тем же пакетом.
